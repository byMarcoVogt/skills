# Table

A content slide in the house frame that compares the same attributes across several items, with a totals row and one highlighted column that carries the message.

The example compares real GDP growth by region for 2025 and the 2026 projection (values illustrative, after IMF World Economic Outlook, October 2026).

## Anatomy

1. **Sticker** (optional): top right, `stamp` in a `navy-700` outline, `radius-stamp`; "Illustrative" when the values are made up.
2. **Action title**: one sentence in `action-title`, `navy-700`, then a 3px `navy-700` rule, `space-4` apart.
3. **Header row**: `footnote` bold in `muted`; the unit stated once (here in the first header cell); a 2px `navy-700` rule below it.
4. **Rows**: item names left-aligned in `body`/`ink`; numbers right-aligned in `tabular-nums`, the same decimals throughout; 1px `hairline` rules between rows; no vertical rules.
5. **Message column**: `navy-700` bold on a `panel` fill, from the header to the totals row.
6. **Totals row**: bold, with a 2px `navy-700` rule above it.
7. **So-what line** (optional): `body-strong` "So what:" in `navy-700`, then `body`, under a 2px `slate-300` rule.
8. **Footer**: 3px `navy-700` rule 98px from the bottom; source left in `footnote`/`muted`; deck name in `body-strong`/`navy-700`, a `slate-300` "|" and the page number right.

## What the consumer provides

The items and their attributes in one unit and scope, with source and vintage; the total; which column or row carries the message; the one-sentence message; and, if it adds something the table does not show, a so-what line.
